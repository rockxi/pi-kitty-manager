# Веб-панель pi-kitty

Веб-панель показывает активных агентов по компьютерам и папкам. Дополнительно можно разрешить переписку и создание новых pi-агентов в kitty. Остановка и подтверждение действий через сайт не поддерживаются.

## Сервер и вход

Сервер запускается через Docker Compose и слушает только `127.0.0.1:8500`. Для локального запуска создайте `.env` с правами `0600`:

```dotenv
admin_login=your-login
admin_password=your-long-unique-password
PI_KITTY_WEB_TOKEN=YOUR_RANDOM_64_CHARACTER_HEX_SECRET
PUBLIC_ORIGIN=http://localhost:8500
TRUST_PROXY=0
```

Секрет для компьютеров можно создать командой `python3 -c 'import secrets; print(secrets.token_hex(32))'`. Не добавляйте `.env` в Git и не публикуйте секрет. Запустите `docker compose up -d --build`, откройте `http://localhost:8500` и войдите по логину и паролю. Ключ в браузер вводить не нужно.

Для публичного размещения обязателен HTTPS reverse proxy: задайте `PUBLIC_ORIGIN` равным точному публичному адресу и `TRUST_PROXY=1` только при доверенном proxy, который сам устанавливает `X-Real-IP`. Backend и kitty Remote Control не должны быть доступны из интернета напрямую. На `asus` используется существующий общий nginx и сертификат Let's Encrypt.

Сессия браузера хранится в защищённой HttpOnly cookie до 8 часов и сбрасывается при перезапуске сервера. Доступен выход. Вход ограничен пятью неудачными попытками за 15 минут на видимый серверу IP. При схеме nginx с TCP-проксированием несколько посетителей могут иметь общий видимый IP и общий лимит. Это однопользовательское приложение без MFA; при интернет-доступе используйте длинный уникальный пароль, а по возможности ограничьте доступ дополнительно на сетевом уровне.

## Подключение компьютера через kitty.conf

На каждом компьютере должен быть файл с **машинным секретом** сервера, доступный только текущему пользователю. Для клиента достаточно строки `PI_KITTY_WEB_TOKEN=...`; логин и пароль администратора копировать на машины не нужно. Добавьте в `~/.config/kitty/kitty.conf`:

```conf
env PI_KITTY_WEB_TOKEN_FILE=/ABSOLUTE/PATH/client.env
env PI_KITTY_WEB_SERVER=https://agents.rockxi.ru
env PI_KITTY_WEB_NAME=My Mac
# Необязательно: разрешить чтение переписки и отправку сообщений.
env PI_KITTY_WEB_CHAT=1
# Необязательно: разрешить создание новых вкладок pi через сайт.
env PI_KITTY_WEB_LAUNCH=1
```

Также необходимы существующий watcher `watcher /ABSOLUTE/PATH/pi-kitty-manager/kitty/autostart.py` и pi extension. Перезапустите kitty и pi: среда уже работающих процессов не меняется при `/reload`. Watcher запускает один клиент на компьютер. Для отключения чата удалите `PI_KITTY_WEB_CHAT` и перезапустите соответствующие pi-процессы.

Для удалённого сервера клиент и расширение подключаются напрямую по HTTPS с проверкой сертификата; SSH-туннель и локальный порт 8500 не нужны. Передача в удалённую сеть по HTTP запрещена; перенаправления не выполняются. HTTP разрешён только для `localhost:8500` и `127.0.0.1:8500`. Секрет из файла не отправляется: используется короткоживущий подписанный токен. Идентификатор хранится в `~/.config/pi-kitty/web-client/machine-id` или `$XDG_CONFIG_HOME/pi-kitty/web-client/machine-id`; не копируйте его между машинами.

Ручной запуск клиента:

```bash
./bin/pi-kitty daemon ensure
python3 -m pi_kitty.web_client --server https://agents.rockxi.ru --token-file /ABSOLUTE/PATH/client.env --name "My Mac"
```

Создание доступно только при `PI_KITTY_WEB_LAUNCH=1`, включённом kitty Remote Control и доступном локальном Unix-сокете kitty. На карточке компьютера нажмите «Новый агент» и укажите абсолютный путь к существующей папке. Создаётся настоящая вкладка kitty с процессом pi; после регистрации она доступна в списке `Ctrl+Shift+P`. Если результат запуска не подтверждён, сначала проверьте kitty: команда не повторяется автоматически. Удалённый запуск увеличивает полномочия владельца логина; включайте его только на доверенных компьютерах и защищайте сайт дополнительным сетевым ограничением.

После остановки клиента компьютер отмечается offline через 20 секунд. Данные состояния и переписки хранятся только в памяти сервера и теряются при его перезапуске; подключённые клиенты присылают их снова.

## Ротация ключей

Машинный секрет не передаётся как bearer-токен: обе стороны вычисляют краткоживущий HMAC-токен, который автоматически меняется каждые пять минут. Сервер принимает текущий и предыдущий интервал для небольшого расхождения часов. Машинный секрет при этом остаётся долгоживущим и должен быть заменён при компрометации; автоматическая ротация bearer-токенов не заменяет его замену.

Чтобы заменить машинный секрет без немедленного отключения всех машин, на сервере задайте новый `PI_KITTY_WEB_TOKEN`, прежний секрет в `PI_KITTY_WEB_PREVIOUS_TOKEN`, и Unix-время окончания переходного периода в `PI_KITTY_WEB_PREVIOUS_UNTIL`. Пересоздайте контейнер, безопасно обновите client.env на каждой машине, затем удалите старый ключ и снова пересоздайте контейнер. Веб-клиент перечитывает файл перед каждой отправкой; extension тоже перечитывает его при каждом опросе. После истечения времени прежний ключ автоматически перестаёт приниматься. Все машины пока используют общий машинный секрет: индивидуального отзыва устройств нет.

## Безопасность и ограничения чата

Имя активного агента можно изменить кнопкой «Переименовать»: изменение передаётся через API pi и сохраняется как имя сессии, поэтому видно и в `Ctrl+Shift+P`. Для уже запущенных pi после обновления расширения выполните `/reload`; переименование доступно только при включённом веб-чате и подтверждается агентом. Пустые новые сессии pi записывает на диск только после первого сообщения; сессии `--no-session` не сохраняются. При потере подтверждения проверьте имя перед повтором.

При включённом веб-чате передаются последние 30 сообщений активной ветки (до 8000 символов каждого). Ответ показывается после завершения, не потоково; поддерживается Markdown без выполнения HTML и без загрузки внешних изображений. Можно прикрепить или вставить до трёх PNG, JPEG или WebP общим размером до 4 МиБ. Изображения передаются в pi как вложения и сохраняются согласно настройкам сессии pi; в истории веб-чата показывается их количество, а не сами изображения. Результаты инструментов не показываются. Для отправки изображений в уже запущенных агентах обновите расширение и выполните `/reload`. Веб-чат включается отдельно через `PI_KITTY_WEB_CHAT=1` и доступен после входа на сайт; владелец логина может поручить агенту действия на машине. Не открывайте доступ недоверенным пользователям.

Отправка доступна, когда агент свободен. Текст передаётся через API pi без расширения slash-команд. Команды доставляются не более одного раза. Если подтверждение доставки потеряно, сайт указывает неопределённый результат; перед повторной отправкой проверьте терминал. Раздельной авторизации устройств и MFA пока нет.
